# Agent Map

Use this map to find the authoritative source before editing. Run `just check-changed` for path-selected source checks; use the listed focused command when a row needs a specific check. Deployment and live probes are separate operations that require authorization. Plans under `docs/superpowers/plans/` are historical records, not current deployment instructions.

| Area | Inspect and edit | Minimum validation | Runbooks and references |
| --- | --- | --- | --- |

| Host storage | `flake/hosts/<host>/disk-config.nix`; `flake/hosts/nas-01/tank-config.nix` | `just check-changed` | `docs/runbooks/nixos-host-deployment.md`; `docs/runbooks/postgres-disaster-recovery.md`; `docs/runbooks/local-registry.md` |

The stable command surface is the `justfile`; `python -m scripts.agent --help` lists the agent CLI subset. Use `just agent-context` for startup, `just task-new|task-resume|task-checkpoint|task-export <id>` for task continuity, `just check-changed` for targeted offline validation, `just doctor` for local readiness, and `just status cluster|network` for bounded read-only live diagnostics.
