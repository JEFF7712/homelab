The stable command surface is the `justfile`; `python -m scripts.agent --help` lists the agent CLI subset. Use `just agent-context` for startup, `just task-new|task-resume|task-checkpoint|task-export <id>` for task continuity, `just check-changed` for targeted offline validation, `just doctor` for local readiness, and `just status cluster|network` for bounded read-only live diagnostics. When multiple agents work concurrently, isolate tasks in Git worktrees (`.worktrees/`).
